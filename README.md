# Salary Management Tool

A full-stack HR salary management platform for 10,000+ employees.
Built following **TDD**, **SOLID principles**, and clean layered architecture.

🔗 **Live demo**: [salary-management-jet.vercel.app](https://salary-management-jet.vercel.app/)


---

## Tech stack

| Layer     | Technology                              |
|-----------|-----------------------------------------|
| Backend   | Node.js · Express · TypeScript · Prisma |
| Database  | SQLite (dev) · SQLite on Railway (prod) |
| Frontend  | React 18 · Vite · TypeScript · Tailwind |
| UI        | shadcn/ui · Recharts                    |
| Testing   | Jest + Supertest (backend) · Vitest + RTL (frontend) |
| CI/CD     | GitHub Actions · Railway · Vercel       |
